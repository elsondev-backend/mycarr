# WelWel Cars

Vitrine de carros esportivos e elétricos feita com **HTML5, CSS3 e JavaScript**, como projeto de estudo de front-end.

**Ver o site:** https://elsondev-backend.github.io/WelCar/

## O que tem no projeto

- **Home** com carrossel animado: setas, indicadores clicáveis, setas do teclado e deslizar o dedo no celular.
- **Saiba Mais** abre a ficha técnica completa de cada carro (análise visual e especificações).
- **Carros**: todos os modelos em cartões, com a ficha técnica em cada um.
- **Contato**: formulário de demonstração (sem envio real).
- Layout responsivo, do celular ao desktop, com menu recolhível no celular.

## Tecnologias

- HTML5 semântico (`header`, `nav`, `main`, `article`, `dialog`, `details`)
- CSS3 com variáveis, Grid, Flexbox, CSS aninhado, `clamp()` e media queries
- JavaScript puro (sem bibliotecas)
- Imagens em WebP

## Estrutura

```
index.html        -> leva para Car/index.html
Car/
  index.html      -> Home (carrossel)
  carros.html     -> Lista de carros
  contato.html    -> Contato
  estyle.css      -> Estilos
  script.js       -> Carrossel, menu, fichas e formulário
  img/            -> Logo, carros e ícones
```

## Rodar no computador

Basta abrir `Car/index.html` no navegador.
